
# RoomVision 3D

RoomVision 3D adalah aplikasi web untuk membantu pengguna merancang interior ruangan secara virtual menggunakan teknologi 3D.

## Features

- 3D Room Visualization
- Room Size Customization
- Wall Color Customization
- Floor Color Customization
- Furniture Library
- Add and Remove Furniture
- Furniture Color Customization
- 3D Camera Rotation
- Zoom Control
- Export Design to JSON

## Technologies

- HTML5
- CSS3
- JavaScript
- Three.js

## How to Run

1. Clone or download this repository.
2. Open index.html in a browser.
3. Make sure you have an internet connection.
4. Start designing your room!
